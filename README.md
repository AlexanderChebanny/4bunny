# 4bunny

Личная страница-визитка: ссылки, интересы и глобус с моей локацией и перелётами.
Чистые HTML, CSS и JS без сборки. Живёт на GitHub Pages:
https://alexanderchebanny.github.io/4bunny/

## Как устроено

- `index.html` — страница целиком: разметка и стили.
- `shared/content.js` — все тексты на русском и английском, ссылки и локация.
- `shared/location.js` — по названию города находит часовой пояс и координаты, показывает время.
- `shared/globe.js` — глобус. Настройки (скорость вращения, зум, задержка возврата) собраны в начале файла.
- `assets/flights.js` — перелёты для глобуса, собираются скриптом из выгрузки Flighty.
- `assets/vendor/` — библиотеки d3-geo, topojson и карта мира, лежат прямо в репозитории, без CDN.

## Запустить локально

```bash
python3 -m http.server 4321
```

Открыть http://localhost:4321. Изменения видны после обновления страницы.

С телефона в той же Wi-Fi сети: http://IP-мака:4321. IP мака:

```bash
ipconfig getifaddr en0
```

## Проверить ветку

Каждая фича делается в своей ветке. Чтобы посмотреть её до вливания в `master`:

```bash
git switch feature/имя-ветки
```

Сервер перезапускать не нужно — достаточно обновить страницу. Вернуться:

```bash
git switch master
```

Список веток: `git branch`.

## Обновить перелёты

1. Во Flighty запросить экспорт данных в настройках. CSV придёт на почту, сохранить в `~/Downloads`.
2. Пересобрать `assets/flights.js`:

   ```bash
   python3 tools/flights.py ~/Downloads/FlightyExport-ДАТА.csv
   ```

   По умолчанию берутся перелёты за последние 12 месяцев, `--months 0` — за всё время.
   В файл попадают только маршруты и страны: без дат, номеров рейсов, PNR и мест.
   Сам CSV в репозиторий не класть.
3. Закоммитить и запушить:

   ```bash
   git add assets/flights.js && git commit -m "Update flights" && git push
   ```

## Выкладка

Всё, что попадает в `master`, GitHub Pages публикует сам через минуту-две.
